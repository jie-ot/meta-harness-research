本目录是 LawBench RSI 预实验的独立实现。本次用户只授权实验1、2、3，预算上限80美元；实验4暂不执行。其他设置以 protocol/执行任务书.md 为准。原工程、原候选、原日志和原响应缓存保留；用户将凭据移到仓库根目录的 .env，配置通过 ../.env 读取。本目录不复制凭据，也不修改 Git 远程。

实验1、2、3已完成：16个正式候选、8次正式优化器会话、8个选优快照、76个阶段、8600次题目预测均通过逐题复核。总日志费用56.810708美元，包含前期5次基础设施故障尝试的13.146295美元；另有2.50美元未知费用保守预留。结论见analysis/给导师的结论.md。analysis/timing_summary.json区分活动时长与包含充值、修复、关机暂停的日历跨度。

数据已使用执行包中的原版 prepare_data.py 完成真实核验：固定官方版本的500题与旧350题逐题匹配且答案一致，新增150题按种子20261003划分为50题评分和100题反馈。训练保留原200题与seed42的实际执行顺序，加载时不再打乱。证据在 external/prepared_data_v3/data_audit.json 与 manifest_v3.json；固定源文件保存在 external/source/3-3.json。

engine/text_classification 是保留原算法与模型参数的框架副本。修改集中于 manifest 入口、完整逐题调用记录、独立响应缓存、阶段状态与计费、优化器访问限制。pilot/run_pilot.py 顺序执行 preflight、noise、round1、round2、predict、holdout、analyze；同轨迹的候选串行，全局最多两条轨迹并发。测试数据和结果位于 external，优化器只访问自己在 runs 中的工作区。这里采用工具白名单和目录隔离，未使用OS级安全边界。

逐题原始 traces.jsonl 与 calls.jsonl 完整保留。优化器首先读取 diagnostics.jsonl，其中包含未截断的输入、预测、答案和对错；长提示词、原始响应及metadata通过相对路径关联至details目录。这样避免重复的完整memory让单行日志超过CLI读取限制。派生视图有独立哈希清单，不修改评分结果，也不产生模型调用。

优化器仍使用原 claude-opus-5-5-code、effort=high 与原 A/B 机制修改约定。为了计数底层重试，CLI请求经过只监听127.0.0.1的计数转发器，原样发送到 .env 中指定的原服务；计数文件不保存认证头或请求正文。逐题任务模型仍是 openrouter/openai/gpt-oss-120b，temperature=0.0，Reasoning: medium，max_tokens=16384。新候选从空memory训练，评分、反馈与外部测试分别加载训练后状态。

在本仓库根目录运行以下命令。默认只做离线预检，不启动模型生成。用户已确认80美元总预算，只执行实验1、2、3；实验4及D50入口被锁住，等待后续明确授权。all按当前授权执行预检、冻结重评、一轮对照、追加第二轮及前三项结果分析。预算是服务商报告及日志估值口径的上限，不能当成实际现金账单。

```powershell
.\lawbench_rsi_v3\run.ps1 -Stage preflight
.\lawbench_rsi_v3\run.ps1 -Stage all -Resume
```

统一入口也支持逐阶段执行，例如 -Stage noise、-Stage round1、-Stage round2、-Stage predict、-Stage holdout 和 -Stage analyze。完成阶段校验哈希后跳过；训练保留逐步检查点，评估保留已完成题目。阶段完成并验证后清理重复的中间检查点，保留完整轨迹、调用记录、费用与完成标记。优化器会话失败、未完成请求费用无法核对、鉴权失败或预算不足时保留记录并暂停，不能自动换模型或重新生成一组候选。

external/status.json 保存当前阶段，external/cost_ledger.jsonl 保存费用事件。第一轮成本快照在补第二轮反馈之前写入。D50必须先有不可回写的 prediction_before_run.json 及其哈希封存文件。history中的评分和反馈不含外部测试成绩；三个旧版本的冻结重评结果也不进入优化器历史。

29项离线检查及完整假模型流程记录在 offline_test_results.txt 与 verification.json，检验数据、真实调用关联、缓存、重试、续跑、成本快照、3D反馈、测试隔离、预测先后顺序与实验4禁用。provider_precheck.json只记录模型列表与只读鉴权查询结果。真实模型结果的独立复核在analysis/output_verification.json，最终实现与凭据扫描记录在implementation_audit.json；图表另经实际渲染与目视检查，记录在plot_validation.json。
