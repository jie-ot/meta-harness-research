事发后，被告人武某主动报警，并组织人员积极抢救被害人，到案后如实供述了自己的罪行。案发后，被告人武某已赔偿被害人近亲属全部经济损失，并取得了被害人近亲属谅解。
对上述事实，被告人武某及其辩护人章某在开庭审理过程中均无异议，且有被告人武某的供述；证人许某某、文某某、沈某某、戴某某、王某某、孙某某、赵某甲、赵某乙等人的证言；书证人口信息表、接处警工作登记表、归案情况说明、事故责任认定报告、工程施工许可证办理指南、工程安全管理办法、江苏省建筑施工特种作业人员管理暂行办法、赔偿协议、收条、谅解书；法医学尸体检验意见书及现场照片等证据予以证实，足以认定。
