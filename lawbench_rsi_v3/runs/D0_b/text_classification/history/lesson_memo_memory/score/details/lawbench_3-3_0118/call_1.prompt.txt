2014年1月22日，被告人王某某在其暂住处被公安人员抓获，公安人员从其住处当场查获上海市国家税务局通用机打发票390份、上海增值税普通发票70份。经鉴定，其中294份上海市国家税务局通用机打发票、70份上海增值税普通发票均系伪造的发票。
被告人王某某被公安人员抓获后，如实交待相关犯罪事实。案发后，惠依莎公司已退缴全部涉案税款。
上述事实，被告人王某某在开庭审理过程中亦无异议，并有经庭审质证属实的证人顾某某的证言笔录、相关增值税专用发票复印件、上海市浦东新区国家税务局稽查局出具的抵扣证明，上海市浦东新区人民法院判决书、公安机关扣押笔录、扣押决定书、扣押清单、上海市浦东新区国家（地方）税务局征收管理处出具的鉴定证明、发票清单，上海市青浦区国家税务局出具的情况说明及附件，公安机关出具的案发经过等证据证实，足以认定。
