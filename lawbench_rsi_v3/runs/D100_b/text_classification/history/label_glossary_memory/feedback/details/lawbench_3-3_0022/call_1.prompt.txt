2016年3月20日，被告人杨某再次利用担任上徐某的职务之便，将上徐村村有资金人民币51765元挪出，用于归还自己经营眼镜厂的银行贷款。
同年3月31日，被告人杨某将挪用的资金悉数归还到村集体账户。2017年2月23日10时许，杨某在台州市椒江区前所街道上徐村2号的家中被台州市公安局椒江分局经侦大队民警传唤到案。
