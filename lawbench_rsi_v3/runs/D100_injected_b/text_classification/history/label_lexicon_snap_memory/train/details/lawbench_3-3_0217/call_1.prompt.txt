2009年上半年的一天晚上，被告人刘某某与黎某1(已判刑)、祝某1(已判刑)、刘某(已判刑)在一起，祝某1接到上级部门通知，说马上要开始办理失地农民养老保险工作，于是四人一起商量，决定用2009年之前县工业园区征用村里土地时多出来的公共面积，为村干部办理一份失地农民养老保险，后祝某1将此事告知了许某(己判刑)，许某表示同意。不久，洋口镇和尚渡村便开始办理失地农民养老保险，具体工作由祝某1负责，刘某配合。村干部把各自的养老保险指标有偿转让给亲戚或者给自己老婆办理，并把参保人员的个人信息材料提供给祝某1、刘某，由祝某1、刘某办理相关手续，其中刘某某提供了亲戚龚某1、龚某3的身份信息材料，同时以办理费用的名义收取了龚某12.6万元现金、龚某22.5万元现金；黎某1提供了其姐姐黎某2、其岳母廖某的身份信息材料，同时以办理费用的名义收取了黎某22.5万元现金、廖某1万元现金；许某提供了其母亲黄某2的身份信息材料，同时以办理费用的名义收取了黄某22.55万元现金；祝某1提供了其姐姐祝某2的身份信息材料，同时以办理费用的名义收取了祝某22万元现金；刘某则以其妻子兰某的名义上报办理养老保险。2009年，广丰县失地农民办理一份养老保险需要交纳养老保险费32760元，征用2.84亩的土地，其土地补偿费和社保补助费加起来刚好可以办理一份失地农民养老保险。祝某1和刘某在填报失地农民养老保险申请时，把2009年之前县工业园区征用村里土地时多出来的19.09亩公共土地分解给没有征用土地的龚某1、龚某2、黎某2、廖某、祝某2、兰某各2.84亩、黄某22.05亩，然后上报广丰县社会保险局，为龚某1、龚某2、黎某2、廖某、祝某2、兰某、黄某2办理了一份失地农民养老保险。案发后，黎某1、许某、祝某1、刘某投案自首，并全部退赃，刘某某（在逃）。2017年3月27日，刘某某投案自首，并全部退赃。
