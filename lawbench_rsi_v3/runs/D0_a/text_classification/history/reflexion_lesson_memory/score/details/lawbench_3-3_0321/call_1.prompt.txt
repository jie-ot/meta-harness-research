- Correct label 【虚开增值税专用发票、用于骗取出口退税、抵扣税款发票;逃税】 (not 「[罪名]虚开增值税专用发票;逃税<eoa>」): 关键在于发票虽为虚开，但被用于骗取出口退税或抵扣税款，属于‘用于骗取出口退税、抵扣税款发票’的情形；仅标记‘虚开增值税专用发票’会遗漏这一重要用途。
- Correct label 【故意伤害;窝藏、包庇】 (not 「[罪名]故意杀人<eoa>」): 判断是否构成故意杀人关键在于是否有明确的杀人故意；本案仅能证明被告人有致人重伤的故意，未能证明其有直接的杀人意图，因此应定为故意伤害，并另加窝藏、包庇罪。
- Correct label 【劫持船只、汽车;抢劫;盗窃】 (not 「[罪名]盗窃;抢劫<eoa>」): 关键在于被告人是否以暴力或威胁强行控制车辆（船只、汽车），这构成劫持船只、汽车罪，而不仅是普通的盗窃或抢劫。
- Correct label 【故意伤害;妨害作证】 (not 「[罪名]故意伤害;伪证<eoa>」): 关键在于行为人是指使、威胁他人作伪证，而不是自己直接作伪证；这种指使、阻碍证人作证的行为属于‘妨害作证’，而不是‘伪证’。因此本案应判‘故意伤害;妨害作证’而非‘故意伤害;伪证’。分类器应判断：若被告是诱使、威胁或阻止他人作伪证，则适用‘妨害作证’，只有被告本人直接提供虚假证言时才适用‘伪证’。
- Correct label 【生产、销售不符合安全标准的食品】 (not 「[罪名]销售不符合安全标准的食品<eoa>」): 关键在于案件事实中被告人不仅销售了不符合安全标准的食品，还自行采购并进行生产加工；因此应使用包含“生产”的罪名，而不是仅仅‘销售不符合安全标准的食品’。
