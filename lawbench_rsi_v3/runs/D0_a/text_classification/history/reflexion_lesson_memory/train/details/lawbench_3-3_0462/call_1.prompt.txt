- Correct label 【开设赌场】 (not 「[罪名]赌博<eoa>」): 关键在于被告人组织、设立并运营具有赌博功能的场所（游戏厅），属于开设赌场行为；而“赌博”仅指个人参与赌局，不涉及场所的设立。判定时应检查是否有设立、提供赌博设施并以营利为目的的行为。
- Correct label 【贪污】 (not 「[罪名]诈骗<eoa>」): 关键特征是被告人利用职务上的公共财产（失地农民养老保险指标）为自己或亲属牟利，属于职务侵占公共财产的行为；诈骗则是通过欺骗私人受害人获取财物。判定为贪污的规则是：若行为人是公职人员，且侵占的是公共财产或公共利益的资金/资源，即为贪污；若是对私人进行欺骗获取财物，则为诈骗。
- Correct label 【非法行医;非法进行节育手术】 (not 「[罪名]非法进行节育手术<eoa>」): 关键在于被告人既未取得医师执业资格而进行胎儿性别鉴定和打胎等医疗活动，构成非法行医；同时其为孕妇实施引产手术，构成非法进行节育手术，两者并存需分别列出。仅标注“非法进行节育手术”漏掉了非法行医的要素。
- Correct label 【伪造公司、企业、事业单位、人民团体印章】 (not 「[罪名]诈骗<eoa>」): 本案的关键在于被告人使用伪造的公司公章和发票专用章，以公司名义进行虚假借款，构成伪造公司、企业、事业单位、人民团体印章罪；而诈骗罪侧重于以欺骗手段非法占有财物，不必涉及印章伪造。
- Correct label 【非法进行节育手术】 (not 「[罪名]非法行医;非法堕胎<eoa>」): 关键在于行为本身是未经许可的节育手术（选择性别的引产），属于《刑法》规定的非法进行节育手术，而不是单纯的非法行医或非法堕胎。非法行医侧重于没有执业资格而提供医疗服务，非法堕胎指未经合法程序的堕胎，但本案的核心罪名是非法实施节育手术。分类规则：若行为人未取得医师资格且实施了堕胎或其他节育手术（尤其含性别选择），应判定为“非法进行节育手术”。

- Correct label 【非法侵入住宅】 (not 「[罪名]盗窃<eoa>」): 本案的关键在于被告人以翻窗方式非法进入他人住宅，这构成‘非法侵入住宅’，而不是单纯的‘盗窃’。只有在未涉及非法进入住宅的情况下，才适用‘盗窃’罪名。

- Correct label 【盗窃;开设赌场】 (not 「[罪名]盗窃<eoa>」): 关键在于识别案件事实中是否同时包含开设赌场等其他犯罪行为；仅有盗窃行为不足以排除开设赌场罪，需要在事实中出现组织、经营赌博场所的描述时加上‘开设赌场’。这与仅标记‘盗窃’不同，因为后者忽略了事实中对赌博场所的设立行为。分类器应检查是否有‘设立、经营、管理赌场或赌博场所’的描述，若有则在标签中加入‘开设赌场’并用分号分隔多个罪名。
