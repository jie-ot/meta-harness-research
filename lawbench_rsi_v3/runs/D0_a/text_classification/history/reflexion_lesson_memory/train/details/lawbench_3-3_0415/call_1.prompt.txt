**Correction lessons — apply these rules when relevant:**
- Correct label 【非法猎捕、杀害珍贵、濒危野生动物】 (not 「[罪名]非法狩猎<eoa>」): 关键在于行为人使用猎套等工具主动捕捉并致死珍贵、濒危野生动物，构成非法猎捕、杀害珍贵、濒危野生动物罪；而“非法狩猎”仅指未经许可的狩猎活动，未必涉及珍贵濒危物种或致死。分类器应检查是否有使用捕猎工具、致死珍贵濒危动物并进行买卖的情节，以判定为非法猎捕、杀害珍贵、濒危野生动物。
- Correct label 【非法拘禁】 (not 「[罪名]非法拘禁;故意伤害<eoa>」): 关键在于被告的行为仅构成非法拘禁，即使受害人受轻微伤，也不构成单独的故意伤害罪，因为伤害情节轻微且属于非法拘禁的从属后果。若伤害未达到《刑法》规定的故意伤害构成要件，则只判非法拘禁。分类器应判断伤害是否达到故意伤害的法定标准，若未达标则仅标注非法拘禁。
- Correct label 【窝藏、包庇;包庇毒品犯罪分子】 (not 「[罪名]制造毒品<eoa>」): 关键在于被告的行为是为制毒嫌疑人提供住所、工具等帮助，属于窝藏、包庇，而不是亲自制造毒品。若事实仅描述帮助、隐匿或包庇毒品犯罪分子，则应判定为“窝藏、包庇;包庇毒品犯罪分子”。
- Correct label 【票据诈骗;信用卡诈骗;合同诈骗】 (not 「[罪名]诈骗<eoa>」): 关键在于案情中明确涉及票据、信用卡和合同等具体诈骗手段，应分别标注为票据诈骗、信用卡诈骗、合同诈骗，而不是笼统的‘诈骗’。
- Correct label 【挪用资金】 (not 「[罪名]职务侵占<eoa>」): 关键在于行为人是企业员工而非国家机关工作人员，且侵占的是公司自有资金而非公共财产；企业内部的资金挪用属于挪用资金，而职务侵占专指国家工作人员侵占公共财产。
- Correct label 【窝藏、包庇;包庇毒品犯罪分子】 (not 「[帮助毒品犯罪]」): 关键在于行为是把已查获的毒品藏匿、销毁以掩饰事实，属于窝藏、包庇；而“帮助毒品犯罪”指的是帮助他人实施贩毒行为，如提供工具、运输等。判别规则：若行为是事后隐匿或销毁毒品证据，则定为窝藏、包庇；若是事前或同步帮助他人进行贩毒，则为帮助毒品犯罪。

- Correct label 【伪造、变造、买卖国家机关公文、证件、印章】 (not 「[罪名]伪造、变造居民身份证<eoa>」): 关键在于辨别被伪造的证件类型：本案涉及的是国家机关出具的《流动人口婚育证明》，属于国家公文类证件，而不是居民身份证；因此应适用“伪造、变造、买卖国家机关公文、证件、印章”。
- Correct label 【失火】 (not 「[罪名]放火<eoa>」): 关键在于行为人是否具有放火的故意；本案被告人在干农活时因疏忽点燃杂草，未表现出故意纵火的主观意图，属于过失引发的火灾，应定为失火而非放火。
- Correct label 【非法占用农用地】 (not 「[罪名]滥伐林木<eoa>」): 关键在于被告将森林资源管护区的林地未经批准直接耕作、播种，构成非法占用农用地，而不是砍伐树木；滥伐林木指的是非法砍伐、毁坏树木本身。
- Correct label 【非法持有、私藏枪支、弹药】 (not 「[罪名]非法持有、私藏枪支、弹药;非法持有毒品<eoa>」): 关键在于案件只涉及非法持有、私藏枪支及弹药，冰毒仅为吸食行为并未构成非法持有毒品罪；因此不应加上‘非法持有毒品’。分类时应判断是否有毒品持有或交易事实，若仅是吸食则不予以‘非法持有毒品’罪名。
- Correct label 【盗窃;伪造、变造居民身份证】 (not 「[罪名]盗窃;伪造居民身份证件<eoa>」): 关键在于准确区分‘伪造、变造居民身份证’与仅‘伪造居民身份证件’，本案涉及伪造并变造身份证信息用于转账和贷款，应标记为‘伪造、变造居民身份证’，而不是简化为‘伪造居民身份证件’。分类规则：若行为同时包括伪造和变造身份证的实际内容或用途，使用‘伪造、变造居民身份证’；若仅为制作假证件则用‘伪造居民身份证件’。
- Correct label 【污染环境】 (not 「[罪名]非法排放污染物<eoa>」): 关键在于行为构成《刑法》规定的污染环境罪，即因非法排放废水导致水体污染，属于‘污染环境’而非单独的‘非法排放污染物’罪名。
- Correct label 【开设赌场】 (not 「[罪名]赌博<eoa>」): 关键在于被告人组织、设立并运营具有赌博功能的场所（游戏厅），属于开设赌场行为；而“赌博”仅指个人参与赌局，不涉及场所的设立。判定时应检查是否有设立、提供赌博设施并以营利为目的的行为。
- Correct label 【贪污】 (not 「[罪名]诈骗<eoa>」): 关键特征是被告人利用职务上的公共财产（失地农民养老保险指标）为自己或亲属牟利，属于职务侵占公共财产的行为；诈骗则是通过欺骗私人受害人获取财物。判定为贪污的规则是：若行为人是公职人员，且侵占的是公共财产或公共利益的资金/资源，即为贪污；若是对私人进行欺骗获取财物，则为诈骗。
- Correct label 【非法行医;非法进行节育手术】 (not 「[罪名]非法进行节育手术<eoa>」): 关键在于被告人既未取得医师执业资格而进行胎儿性别鉴定和打胎等医疗活动，构成非法行医；同时其为孕妇实施引产手术，构成非法进行节育手术，两者并存需分别列出。仅标注“非法进行节育手术”漏掉了非法行医的要素。
- Correct label 【伪造公司、企业、事业单位、人民团体印章】 (not 「[罪名]诈骗<eoa>」): 本案的关键在于被告人使用伪造的公司公章和发票专用章，以公司名义进行虚假借款，构成伪造公司、企业、事业单位、人民团体印章罪；而诈骗罪侧重于以欺骗手段非法占有财物，不必涉及印章伪造。
- Correct label 【非法进行节育手术】 (not 「[罪名]非法行医;非法堕胎<eoa>」): 关键在于行为本身是未经许可的节育手术（选择性别的引产），属于《刑法》规定的非法进行节育手术，而不是单纯的非法行医或非法堕胎。非法行医侧重于没有执业资格而提供医疗服务，非法堕胎指未经合法程序的堕胎，但本案的核心罪名是非法实施节育手术。分类规则：若行为人未取得医师资格且实施了堕胎或其他节育手术（尤其含性别选择），应判定为“非法进行节育手术”。
- Correct label 【贪污】 (not 「[罪名]职务侵占<eoa>」): 关键在于被告人利用职务之便侵占的是国家扶贫专项资金等公共财产，属于公职人员对国家财产的贪污；职务侵占则针对的是单位财产且不一定是国家资金。规则：若行为人是公职人员且侵占的是国家或公共财政资金，判贪污；若侵占的是单位财产且不涉及国家资金，判职务侵占。
- Correct label 【赌博】 (not 「[罪名]开设赌场<eoa>」): 关键在于行为是组织、进行赌博并获利，而不是设立公开的赌场场所；因此应判定为‘赌博’而非‘开设赌场’。
- Correct label 【非法侵入住宅】 (not 「[罪名]盗窃<eoa>」): 本案的关键在于被告人以翻窗方式非法进入他人住宅，这构成‘非法侵入住宅’，而不是单纯的‘盗窃’。只有在未涉及非法进入住宅的情况下，才适用‘盗窃’罪名。
- Correct label 【失火】 (not 「[罪名]过失以危险方法危害公共安全<eoa>」): 关键在于行为导致森林火灾，属于《刑法》规定的失火罪；过失以危险方法危害公共安全要求使用危险手段危害公共安全的情形，不专指森林火灾。判定时，只要是因过失点燃林区而引发火灾，即适用失火罪。
- Correct label 【生产、销售有毒、有害食品】 (not 「[罪名]非法持有毒品<eoa>」): 关键在于行为人是以出售、销售的方式向他人提供含有西地那非等有害成分的“藏药王”“黑倍王”，属于生产、销售有毒、有害食品，而非法持有毒品仅指个人非法持有受管制的毒品，不涉及商业销售。
- Correct label 【虚开增值税专用发票、用于骗取出口退税、抵扣税款发票】 (not 「[罪名]虚开增值税专用发票、用于骗取出口退税、抵扣税款发票;经济犯<eoa>」): 关键在于案件事实只涉及虚开增值税专用发票用于骗取出口退税和抵扣税款的行为，这是《刑法》规定的单一罪名，不应再附加“经济犯”等宽泛标签。
- Correct label 【盗窃;掩饰、隐瞒犯罪所得、犯罪所得收益】 (not 「[罪名]盗窃<eoa>」): 本案除多次盗窃行为外，被告人还将盗得的车辆、冰箱等财物藏匿、转移并隐瞒其来源，构成掩饰、隐瞒犯罪所得；因此应在“盗窃”之外加上“掩饰、隐瞒犯罪所得、犯罪所得收益”。
