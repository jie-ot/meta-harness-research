**推理分析**  
1. 被告人以“炎黄母族故里平逢山景区”项目为幌子，伪造中国建设银行的三亿元存、取款凭条，冒充李2某为其亲属及台湾分会会长，诱骗受害人投资。  
2. 在项目未获土地、环评等合法审批、且无施工条件的情况下，仍以同一项目名义与多家施工单位签订合同，收取图纸押金、合同保证金等费用。  
3. 以上行为属于**以非法占有为目的，使用虚构的事实和隐瞒真相的方法，骗取公私财物**，符合《中华人民共和国刑法》第二百六十六条规定的**诈骗罪**。  
4. 同时，行为人伪造银行凭条，涉及**伪造金融票据罪**（刑法第二百二十七条），但核心犯罪是以欺骗手段获取财物的诈骗行为。  

**结论**：本案事实主要构成诈骗罪（并可并案适用伪造金融票据罪）。
