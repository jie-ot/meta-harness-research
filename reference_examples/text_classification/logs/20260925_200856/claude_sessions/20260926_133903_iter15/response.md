**Two hypotheses:**

1. **Tentative-prediction-guided retrieval (Exploitation)**: Instead of using retrieved example labels as a proxy for the model's likely prediction, make a cheap first-pass LLM call on a minimal context to get a tentative label, then use that tentative label to look up its confusion neighbors, build the final enriched context, and make the real prediction. This is mechanistically new — no prior system has done per-segment similarity.
