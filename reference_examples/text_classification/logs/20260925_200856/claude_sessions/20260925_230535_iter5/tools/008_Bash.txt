## Why the plateau
Iterations 2 and 3 all varied axis C (selection algorithm). Jaccard similarity is the ceiling here: all four variants (plain similarity, balanced, champion, MMR) saturate the same ~45-46% band because they all draw from the same token-overlap signal and the same flat Q/A prompt format. Champion slightly edges MMR because explicit label coverage beats probabilistic diversity for tasks with many rare classes and sparse training data.

MMR's slight regression vs plain similarity suggests that for these datasets, the redundancy penalty in MMR removes genuinely useful near-duplicate examples that reinforce correct labels.
