`llm_rule_synthesis_memory` (exploration) — adds a new memory type: short pairwise decision rules synthesised by a single LLM call whenever a confusion pair reaches a count threshold. This is a fundamentally different mechanism from raw example retrieval — the model receives explicit natural-language boundary descriptions drawn from its own measured error patterns, rather than having to infer those boundaries from examples.
